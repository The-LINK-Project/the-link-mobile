# Lesson visuals

These are generated, illustrative Singapore scenes rather than photographs of
named people, businesses, clinics, stations, or worksites. They deliberately
avoid real logos and readable private information.

- `mrt-*`: a Singapore MRT platform, exit, and fare-gate action
- `hawker-centre`, `chicken-rice`, `takeaway`, `drink`: a neighbourhood hawker-centre visit
- `clinic-reception`, `fever`, `medicine`: a neighbourhood clinic visit
- `work-safety`, `dangerous`, `day-off`, `break`, `hurt`: work and rest situations in Singapore

The lesson UI uses a photo only when one frame communicates the meaning clearly.
Abstract vocabulary continues to use the app's existing icon system.
